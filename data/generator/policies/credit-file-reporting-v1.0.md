# Credit File Reporting Policy

Version 1.0. Effective from 4 March 2024.

## 1. Accuracy

Report payments to credit reference agencies accurately each month.

## 2. Corrections

Correct an inaccurate entry within ten working days. Accurate entries must not be removed as a gesture of goodwill.

## 3. Complaints

Do not uphold a complaint about an entry that matches the payment history.
